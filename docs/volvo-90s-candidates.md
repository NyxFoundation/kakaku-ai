# 90年代ボルボ 候補リスト（2026-08-26 時点）

友人からの条件：

- ちょっと古い系の車、90年代のボルボとか
- **デザイン・走行距離・値段**で見ている
- なるべく**状態が良い綺麗なもの**

再現コマンド：

```sh
uv run python scripts/find_candidates.py --maker ボルボ \
    --year-from 1988 --year-to 2001 --json /tmp/volvo90s.json
```

データ元はカーセンサーの在庫（**167台**、修復歴なしに限ると 145台）と、
ヤフオクの過去180日の落札実績（2001年式以前のボルボ **15台**）。

---

## 1. まず知っておくべきこと — 90年代ボルボはもう「安い古い車」ではない

同じモデルでも、店頭価格とオークション落札価格が **2〜3倍** 開いている。

| モデル | カーセンサー店頭 | ヤフオク落札（180日） |
|---|---|---|
| 240 / 240エステート | 100〜378万（中央値 **212〜220万**） | 75〜130万 |
| 940 / 940エステート | 77〜364万（中央値 **99〜179万**） | 30〜50万 |
| 850 / 850エステート | 90〜440万（中央値 **146〜156万**） | 70万 |
| 960 / S90 / V90 | 50〜269万（中央値 **114〜166万**） | 10万 |
| V70（初代） | 13〜183万（中央値 **100万**） | 80万 |

240 が突出して高い。1993年で生産終了して30年以上経ち、完全にコレクター相場に
入っている。カーセンサーで低走行の 240 を買うと **240〜350万**、ヤフオクで
探しても 8〜13万km 台で 75〜130万（入札 77件・85件と競り合いも激しい）。

**「デザインが好き」で 240 を選ぶのは合理的だが、値段の条件とはぶつかる。**
デザインの方向性が近くて価格がこなれているのは **960 / 940 / 850**。

## 3. 本命 3台

### ① 850 GLT 1994年 / 4.5万km / 135.5万円 ★イチオシ

`ディーラー記録簿 タイベル交換済み SR`
https://www.carsensor.net/usedcar/detail/VU8117907657/index.html

30年落ちで **4.5万km は同年式中央値の半分以下**。この年代でいちばん怖いのは
「整備履歴が分からない」ことで、ディーラー記録簿＋タイベル交換済みでそこが
潰れている。同年式相場 154万に対して 135万。850 は FF・直列5気筒で 240 より
普通に走れて、部品もまだ出る。サンルーフ付き。

### ② V70 2.5T 1998年 / 4.5万km / 125.2万円

`1オーナー サンルーフ タイベル交換済`
https://www.carsensor.net/usedcar/detail/AU4171757592/index.html

初代 V70（850 の正常進化版）。1オーナー・4.5万km・タイベル済み。実用性は
この中で最高で、価格もこなれている。デザインは 240 ほど尖っていないが、
角ばったボルボの最後の世代。

### ③ 960 ベースモデル 1992年 / 3.8万km / 178.6万円

`禁煙車 評価点4.5点 ノーマル車輌 直6 3.0L ガラスコーティング施工済`
https://www.carsensor.net/usedcar/detail/AU6927274713/index.html

**評価点 4.5 が明記されている数少ない個体**（30年落ちでこの評価点はかなり珍しい）。
3.8万km、車検 2027/11 まで残 15ヶ月。960 は「240 に近い角ばったデザインのまま
中身が新しい」ポジションで、90年代ボルボの隠れた正解。

## 5. 買う前に確認すべきこと

- **タイミングベルト交換履歴** — この年代で最重要。切れると即エンジン全損。
  本命3台はいずれも交換済み明記。記載がない個体は交換費用 10〜15万を上乗せで見る
- **「価格応談」の 12台** — 問い合わせないと値が分からない。低走行の 240 に多く、
  高く出る可能性が高い
- **車検残** — S90 1997年（2.5万km / 149.8万）は残り1ヶ月。取り直しで +15〜25万
- **修復歴あり 12台** — このリストからは全部除外している。240 系に 9台と集中
- **オークション相場との差** — ヤフオクなら店頭の 1/2〜1/3 で買えるが、現車確認が
  できず、車検・名義変更・陸送を自分で手配する必要がある。整備前提で買える人向け

## 6. 順位づけの根拠

`scripts/find_candidates.py` のスコアは以下の加減点。デザインは数値化できないので
一切触れていない（グレード・装備の載った出品タイトルを並記して目視判断に委ねる）。

| 項目 | 加減点 |
|---|---|
| 走行が同年式中央値の 50% 以下 | +3.0 |
| 走行が同年式中央値の 80% 以下 | +1.5 |
| 走行が同年式中央値の 150% 以上 | −1.5 |
| 修復歴なし | +2.0 |
| 修復歴あり | −4.0 |
| 車検残 | +（残月数/12、最大 +2.0） |
| 車検整備付 | +1.0 |
| 保証付 | +1.0 |
| 同年式中央値の 60〜90% の価格 | +1.0 |
| 同年式中央値の 50% 未満の価格 | **−1.0**（安すぎには理由があることが多い） |
