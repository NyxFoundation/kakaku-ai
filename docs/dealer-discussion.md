# スポーツカー中古車ディーラーとの打ち合わせメモ

相手はプロで、相場観は我々より確実に上。**「相場を教えます」は刺さらない。**
刺さるとしたら、プロが毎日見ているのに数字にできていない部分 —
**個人間取引（ヤフオク）の全数**、**時間軸**、**流通の速さ** の 3 つ。

この 3 つはディーラーの立ち位置から見えにくい。業者オークション（USS / TAA）は
会員でないと見られないが、逆に**ヤフオクの個人間は誰でも見られるのに誰も全数を
数えていない**。そこが持っていける手土産になる。

---

## 1. いま持っているもの（話の入り口）

### ヤフオク落札 180日分を**全数**取っている

中古車ノードの落札 **30,382件を取りこぼしなく**取得済み（100%）。
ページングが 15,050件で頭打ちになるので、並び順を変えて複数回さらって
名寄せしている。うちスポーツカー系は **1,965件**。

| 車種 | 落札数 | 落札中央値 | 入札数の中央値 | 個人出品率 |
|---|---:|---:|---:|---:|
| コペン | 233 | 28万 | 46 | 94% |
| フェアレディZ | 146 | 80万 | 40 | 93% |
| ロードスター | 146 | 55万 | 38 | 95% |
| シルビア | 109 | 170万 | 38 | 97% |
| RX-8 | 94 | 40万 | 42 | 97% |
| ビート | 86 | 40万 | 32 | 99% |
| 86 | 84 | 89万 | 64 | 93% |
| ユーノスロードスター | 66 | 69万 | 44 | **100%** |
| カプチーノ | 65 | 45万 | 66 | 98% |
| RX-7 | 37 | 232万 | 62 | 95% |
| 180SX | 35 | 170万 | 47 | **100%** |

**この表でいちばん効くのは右 2 列。**

- **個人出品率が 93〜100%** — スポーツカーのヤフオクは、業者の販路ではなく
  ほぼ純粋な個人間市場。つまりディーラーの店頭相場とは**別の需給**で動いている。
  仕入れ先としても、手放す個人の受け皿としても、ここは競合であり供給源でもある
- **入札数** — カプチーノ 66回、86が 64回、RX-7 が 62回。一方でビートルは 17回。
  同じ価格帯でも入札の厚みがまるで違う。これは**買い手の厚み**の代理指標になる

### 店頭在庫も個体単位で追っている

カーセンサーの掲載を 1台ずつ、`listing_id` で継続追跡している。取れるのは

- 支払総額・車両本体価格・走行距離・修復歴・車検残・保証
- **値下げ履歴**（いつ、いくら下げたか）
- **掲載が消えた日**（＝売れたとみなせる）

店頭の**成約価格は世の中のどこにも公開されていない**。掲載消滅と直前の
提示価格を突き合わせるのが、外から見える唯一の手がかりになる。

### 整備情報は「壊れやすい点」として数字にしてある

国交省の不具合情報（ユーザー通報）を **世代 × 装置**で集計。1件ずつに
型式・初度登録年月・**発生時の走行距離**・症状の全文が付く。

ここで価値があるのは **発生時走行距離の中央値**。
「この装置はだいたい何万kmで来る」が言えるので、整備の見積もり根拠になるし、
客への説明材料にもなる。「壊れやすいらしい」ではなく
「○万km 時点の通報が n 件」と言える。

リコール届出も別途取ってあるので、「この個体はこのリコールを消化済みか」を
確認する材料になる。

### 口コミ

みんカラのレビューを個票で。年式・グレード・6軸スコア・満足点・不満点・総評。
**これは正直いちばん価値が薄い。** 販売の役には立つが、相場も整備も動かさない。
話の主役にはしない。

## 2. ディーラーに何を渡せるか

相手の困りごとから逆算すると、たぶんこの 4 つ。

### (a) 仕入れの機会損失

いまヤフオクに出ている個体が、店頭相場に対して安いのか高いのかを
**即座に**判定して通知する仕組みは既に動いている。年式ごとの相場に
走行距離の効きを乗せたモデルで、修復歴なしに絞って Slack に投げている。

スポーツカー向けには、ここに**入札の厚み**を足すと意味が変わる。
「安い」だけでなく「安いのに入札が伸びていない ＝ 見落とされている」
が拾えるようになる。

### (b) 手放す客の受け皿としての価格提示

「うちに売るといくら、ヤフオクに自分で出すといくら」を並べて示せる。
個人出品率 95% の市場なので、客は実際にその選択をしている。
**数字で示せれば買取の説得力になる**（あるいは「ヤフオクのほうが高いですよ」
と正直に言える関係を作る材料になる）。

### (c) 在庫の値付けと引き際

値下げ履歴と掲載消滅日が貯まると、
「この車種はこの価格帯で平均○日で売れる」「○日超えたら下げないと動かない」
が言えるようになる。**在庫回転は利益に直結する**ので、ここは実利がある。
ただし後述のとおり、意味のある精度に達するには数か月の蓄積が要る。

### (d) 相場が動く前に気づく

これが本命だが、いちばん難しい。§5 で正直に書く。

## 3. 逆にディーラーからもらいたいもの

こちらが持っていないデータを相手は持っている。**対等な交換にしたい。**

| 欲しいもの | なぜ |
|---|---|
| **業者オークションの成約実績**（USS / TAA） | 卸値。全部の起点だが会員でないと見られない |
| **実際の成約価格**（掲載価格ではなく） | 掲載消滅から推定している部分を答え合わせできる |
| **仕入値と在庫日数** | 回転率のモデルが一気に現実的になる |
| **問い合わせ数 / 見学数** | 掲載価格と成約の間にある需要の指標 |
| **評価点（AIS等）の実際** | 「評価点4.5」が価格にどう効くか定量化できる |
| どの車種で困っているか | 分析の的を絞る。全車種やっても薄まる |

とくに**業者オークションの成約と、我々が持つヤフオク個人間の全数**を
突き合わせられると、**卸 → 個人間 → 店頭 の 3 層の価格差**が初めて見える。
これは業界の誰も持っていないはず。ここが一番のフックになる。

## 4. 入札の時系列を取る（今後やること）

### なぜ必要か

いま取れているのは**終わった後の入札「総数」だけ**。
「いつ、いくらで、何人が入ったか」の過程が落ちている。
経済学的に面白いのは全部そこにある。

### 取り方

ヤフオクの入札履歴ページ（`/jp/show/bid_history`）は **robots.txt で
Disallow されている**ので使えない。したがって

**出品中の一覧を定期的に撮って、自分で曲線を組み立てる。**

出品中の検索（`/carsearch`）は robots で禁じられておらず、1件ごとに
現在価格・入札数・終了時刻・開始時刻が付いてくる。これを繰り返し撮れば
`(auction_id, 観測時刻) → 現在価格, 入札数` の時系列になる。

頻度は 2 段構えにする。終盤に情報が集中するため。

- **1日1回** 全出品をさらう（母集団の把握・新規出品の検知）
- **1時間ごと** 終了24時間以内のものだけ（ここで価格が跳ねる）

終了後に落札側と `auction_id` で突き合わせれば、
**入札曲線 + 最終結果**が 1本のレコードになる。

### 貯まると何が見えるか

- **スナイプ率** — 最後の10分で価格が何%動くか。車種で違うはず
- **初動と結果の関係** — 序盤の入札で最終価格がどこまで説明できるか
- **開始価格の設計** — 1円スタートと高め開始で、最終価格に差が出るか
  （オークション理論では低い開始価格が参加者を増やして最終価格を押し上げる、
  という予測がある。実データで検証できる）
- **終了曜日・時刻の効き** — 日曜夜 vs 平日昼で落札額が違うか。
  出品側へのアドバイスになるし、入札側なら**平日昼の穴**を狙える
- **即決の使われ方** — 即決が押される価格帯と、競りに任せたほうが伸びる価格帯

**注意点として先に言っておくべきこと:** 終了間際の観測は「観測したから
入札した」の逆で、こちらは見ているだけなので市場に影響しない。ただし
**通知を出して実際に入札するようになると、自分の行動がデータを汚す**。
自分の入札は必ず記録して分離する。

## 5. 流通から相場変動を予測できるか

**正直な見立て: 方向と大きさの「傾向」は当てられる。個別車両の落札額は当たらない。**

### 当てられそうなもの

**先行指標になりうるのは価格そのものではなく「流れの速さ」。**

| 指標 | 取り方 | 何の前触れか |
|---|---|---|
| 在庫回転日数 | 掲載開始 → 掲載消滅 | 短くなる = 需要超過 → 数週後に値上がり |
| 値下げ率 | 値下げ履歴 | 下げないと動かない = 需要減 |
| 出品数 vs 落札数 | ヤフオク全数 | 供給の変化。玉が枯れると上がる |
| 入札参加の厚み | 入札曲線 | 買い手の数。価格より先に動く |
| 不落率 | 出品されたが落札されなかった割合 | 売り手希望と買い手評価の乖離 |

在庫回転は普通、価格より先に動く。売れ行きが良くなってから値上げが起きるので、
**回転日数の短縮は数週間の先行指標**になりうる。ここは検証する価値がある。

### 当てられないもの

- **個別車両の落札額** — 個体差（程度・整備歴・色・グレード・写真の質）が
  支配的で、しかもそのほとんどがデータに乗らない。
  スポーツカーは特に改造の有無で倍違う
- **突発イベント** — 生産終了発表、規制、メディア露出、映画。
  これらは一晩で相場を変えるが予測不能。事後に検知して**理由を説明する**ことはできる
- **短期の細かい上下** — ノイズ。週次データで日次の動きは追えない

### いつまで待てば検証できるか

正直に言うべき点。

- ヤフオクの落札は**過去180日しか遡れない**。これは Yahoo 側の制約で回避できない。
  週次で撮り続けて名寄せすれば実効期間は伸びていくが、**過去には戻れない**
- 回転日数のモデルは、掲載 → 消滅の完結サイクルが要る。
  スポーツカーの回転を考えると**最低 3〜6か月**の蓄積
- 季節性を言うには **1年以上**

つまり「いまから積み上げれば来年には言える」であって、
**いま予測モデルを出せるわけではない**。ここを盛ると信用を失う。

### 現実的な最初の一歩

予測の前に、**記述**で十分な価値がある。

「この車種はいま在庫が○台、平均○日で売れていて、
ヤフオクでは月○台が個人間で動いていて中央値は○万円。
店頭との差は○%。3か月前と比べて回転は○日縮まっている」

これが毎週自動で出てくるだけでも、プロが勘でやっていることの
**答え合わせ**になる。予測を売るのは、これが半年動いてからでいい。

## 6. 打ち合わせでの進め方

1. **手土産から入る** — スポーツカー1,965件の落札全数と個人出品率95%の表。
   「こんなの見たことない」となるかを見る
2. **困りごとを聞く** — 仕入れか、値付けか、回転か、客への説明か。
   分析の的が決まらないと何も刺さらない
3. **交換条件を出す** — 業者オークションの成約と在庫日数をもらえないか。
   出せない部分（守秘、規約）がどこかも確認する
4. **予測は約束しない** — 「いまから積めば来年言える」と正確に言う。
   代わりに記述の週次レポートを先に出す
5. **入札時系列の設計を見せて意見をもらう** — 頻度と対象車種。
   プロの肌感で「そこは効かない」が出れば設計が締まる

### 確認しておくこと（法務・規約）

- ヤフオクの入札履歴ページは robots.txt で禁止。使わない
- 業者オークションのデータは会員規約があるはず。もらう場合は
  **二次利用の可否を書面で確認**してから設計に入る
- ディーラーの在庫・仕入値は営業秘密。どこまで表に出せるかを最初に決める
