# ミニバン候補の比較（2代目で引き直し）

`life#16` で候補を 3 車種に絞ったので、その年式範囲だけで相場と維持費を並べ直したもの。
年式の下限は国交省の不具合通報を年式別に見て決めた（[経緯](https://github.com/grandchildrice/life/issues/16#issuecomment-5474857620)）。

* **フリード 2017年式〜** — 2代目（GB5〜GB8）。初代134件に対し7年で3件
* **ノア 2016年式〜** — 80系が落ち着くのが2016年式から。2015年式は 8.7件/100台でワースト
* **ヴォクシー 2017年式〜** — 2017年式で1.5、2018年式で0.8まで落ちる

✅ は支払総額 200万円以内に収まる年式。

## 読み方

### 予算200万で買えるのは限られる

- **フリード 2017〜2021年式**（137〜196万）— 5年ぶん選べる
- **ノア 2016〜2017年式**（147〜181万）— 2年ぶん
- **ヴォクシー 2017年式のみ**（192万）— ぎりぎり1年ぶん

ヴォクシーは 2018年式で 215万になり予算を超える。**同じ80系でもノアのほうが安い**
（2016年式 147万 vs ヴォクシー 2017年式 192万）のは、ヴォクシーのほうが人気で
玉数も多いぶん値が落ちにくいため。掲載台数もヴォクシー 520台に対しノア 236台。

### 落札相場はあてにしないほうがいい

落札 n の列を見ると、対象年式では **0〜10件** しかない。2代目フリードや80系ノア/
ヴォクシーはまだ個人売買に出てこず、ほぼディーラー流通だから。

「店頭が高い」が +150% を超える行があるが、これは**落札側のサンプルが薄いだけ**で
実際にその値段で買えるわけではない。たとえばフリード2017年式は落札52万に見えるが
n=10 で、しかも落札側は走行15万km・小売側は走行7万km台と中身が違う。

**この3車種については小売相場（掲載台数150〜990台）を見るべき。**

### 維持費は「安く買うほど総額も安い」が素直に効く

10年累計で見ると

- フリード 2017〜2019年式 → **396〜402万**
- ノア 2016年式 → **445万**
- ヴォクシー 2017年式 → **570万**

フリードが安いのは 1.5L（自動車税 30,500円 / 重量税区分 1.5t）で燃料も
15km/L 想定だから。ノア・ヴォクシーは 2.0L で税も燃費も一段重い。

ただし**フリードは3列目が狭い**ので、7人乗りとしての使い勝手は別物。
そこは数字に出ないので現車で確認すること。

### 2022年式以降（90系ノア/ヴォクシー）は様子見

- ノア 2022年式 4.9件/100台、2023年式 2.5件/100台
- 装置別では制動装置が最多（ノア90系で15件）

80系後期（2018〜2021）が 0.3〜2.0 で落ち着いているのと比べると、まだ高い。
予算的にも 345万〜で届かない。

## 注意

- **通報/100台 は発生確率ではない。** 分母は「いま中古車市場に出ている台数」で
  実際の保有台数ではないし、不具合に遭っても通報する人はごく一部。
  **年式間の相対比較にだけ使う数字**
- 維持費のうち税・自賠責・車検・燃料は確度が高いが、**値落ちと修理は仮定を含む**。
  修理は「発生距離を通過する装置の修理費 × 0.5」で、この 0.5 は素の仮定
- 落札データが無い年式は小売中央値を買値として計算している（新しい年式ほど
  落札に出てこないため）

```sh
uv run kakaku-ai books --only minivan     # souba_minivan.xlsx を作り直す

```
